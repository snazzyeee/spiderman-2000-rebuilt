# Security policy

Please report security problems privately through GitHub's
**Security → Report a vulnerability** form on this repository, not in public
issues or pull requests.

Relevant reports include problems in the tools or launcher scripts (for example,
unsafe archive extraction, path traversal or unverified downloads), the CI
workflow, or accidentally committed secrets or personal data.

If you find original game content or other material that should not be in this
repository, report it the same way so it can be removed promptly.

This is a volunteer project; there is no bounty and no guaranteed response time,
but reports will be acknowledged as soon as possible.
